# 2. Attempt Calendar & Terminology

- **"Jan 27" / "January 27" / "Jan 2027"** = the January 2027 CA Inter attempt — the next upcoming
  cycle relative to today (Sep 2026). A student "writing Jan 27" or "targeting Jan 27" intends to
  sit that exam.
- **"Sep 26" / "September 26" / "Sep 2026"** = the September 2026 attempt, held in the first half
  of September 2026 (Group I papers first, Group II papers a few days later). By mid-to-late
  September 2026 this attempt has **already been written** — so "gave Sep 26" means the student
  already sat that exam and is typically now waiting on results or regrouping for the next attempt.
- There is also a **May** cycle each year; a student may mention "May 27" instead of Jan — don't
  force a Jan-vs-Sep binary if the text clearly says May.
- A student can be in exactly one of these buckets for this conversation's purpose:
  - **Preparing for Jan 27** (upcoming, not yet written)
  - **Already gave Sep 26** (just wrote it, results pending or out)
  - **Targeting a later attempt** (e.g., May 27 or beyond) — capture as other with the stated month
  - **Unclear / not stated**
